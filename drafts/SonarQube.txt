#SonarQube:
=============================================
~ SonarQube is a very popular code quality checking tool
~ With the help of SonarQube we can perform the code review to identify the developers mistakes in code

~ Within SonarQube topic we have various parameters like Sonar Iuuses, Sonar Quality profiles,Sonar Quality gate and so on

~ SonarQube is developed using java language however,
~ SonarQube supports 30+ programming languages to perform code quality check or code review

~ We can perform Code review using SonarQube either by adding it to our end to end CICD pipelines or separately as per the use case
~ It is the responsibility of devOps engineers to generate Project code review report and share them with dev teams
~ While Development team are responsible to fix sonar issues

~ Sonar Issues : 
—> These are the problems in the code  which are identified by SonarQube
	-> Bugs(danger, whatever harms our code execution may cause
	-> Vulnerabilities(security hotspots)
	-> Duplicate Code blocked(repeated code)
	-> Code smells
	-> Code Coverage(How many lines of code is tested in unit testing	
	
~ Sonar Quality profile : 
—> It sets some of the rules to perform code review					 
—> Various languages have their own quality profiles such as java quality profile,Python quality profile and so on
—> In SonarQube, for every programming language one Quality profile is available with some set of rules tp perform code review	
—> SonarQube identifies which programming language is used by our project and based on it performs code reviews
eg. Python Project —> Python Quality Profile —> Python rules
      Java Project —> Java Quality Profile —> Java rules

~ Sonar Quality Gate:
—> Quality Gate represents overall project code quality is passed or not (Customisable)	
—> If Code quality fails we should not deploy our code 

*We require to install Docker in our setup then further install SonarQube

#SonarQube-Setup:
=============================================
~ Create Ec2 instance(t2.small or t2.medium) Amazon Linux VM
~ Install Docker

#Installation-of-SonarQube:
=================================================
~ Create an Ec2 instance of type t2.medium or higher 
~ The node type is selected so due to memory requirements
~ Connect in terminal via ssh
~ Install docker
-> sudo yum install docker -y
-> sudo systemctl start docker
-> sudo systemctl enable docker
-> sudo user mod -aG docker ec2-user
-> exit and reconnect
~ Check if docker is installed properly using : docker -v

~ SonarQube is a paid software
~ Use the lts version which is basically free community version
~ Now to install sonarQube run the following command
—> docker pull sonarqube:lts-community
—>  docker run -d \
  	--name sonarqube \
  	-p 9000:9000 \
  	sonarqube:lts-community

*The port no. For sonarQube container is 9000
*Also in inbound rules of the VM configure the port no. 9000

~ Now copy the public id and search in browser as
-> <public-ip-VM>:9000

*We’ll be at the login page of SonarQube
~ Login using “admin” for both the username and password 
~ Next up, Change the password for security reasons
~ After that we’ll be at the home page of SonarQube

~ As discussed earlier Quality rules are programming language specific and for example are as :
Java ~ 628
Python ~ 230 
And so on…..

*Quality Gate can be configured as per our own choice to check for code
*We can also configure rules in Quality Profiles as per our own choice 
*For a DevOps we have to check for default rules only 

~ Creation of Tokens:
~ We can create tokens by navigating to Security
~ Home -> Profile -> My Account -> Security -> Create Token
*To create a token give a name and select token to be of type “Global Analysis Token”
